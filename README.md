# Improved Calculator

A beginner-friendly calculator built using Python.

# Live Demo:

https://improved-calculator-python-ari3sbtcnfyebttnb3qhhs.streamlit.app/

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Floor Division
- Modulus
- Power
- Invalid Operator Handling
- Division by Zero Handling
- Positive / Negative / Zero Classification

## Technologies

- Python
- Jupyter Notebook
